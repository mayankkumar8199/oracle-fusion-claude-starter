## 5. Working in the Fusion user interface for P2P and O2C

This section maps P2P and O2C work to 26D work areas, pages and roles, shows which pages are Redwood and how to switch them on, and lists the UI tools for spreadsheets, processes, setup, approvals and extensions. Tables: section 9 and Appendix A. Roles: section 12. Agents: sections 10 and 11.

### 5.1 Navigation fundamentals as of 26D

| Element | How it works in 26D | P2P/O2C tip |
|---|---|---|
| Home page | Global header, tabs (one per Navigator group) with Apps icons and Quick Actions (Show More lists all). Sections: Things to Finish, News and Announcements, Analytics (infolets). | Personalize Springboard icon hides or shows Apps icons for you. Setup and Maintenance sits in the Others tab. |
| Navigator | All work areas you can access, in groups; Show More expands them. | Paths used below: Navigator > Payables > Invoices, Procurement > My Receipts, Supply Chain Execution > Inventory Management, Receivables > Billing, Cash Management > Cash Balances, ERP Agents (26C and later). Administrators can change groups in Structure (5.8). |
| Tasks panel tab | Classic landing pages have a Tasks panel tab; some add a Reports and Analytics panel tab. | Most Payables, Receivables, Cash and Purchasing tasks start here. |
| Global Search | Keyword search across business objects, when enabled; filters and saved searches. | With Redwood Self Service Procurement as default, requisition hits open the Redwood Requisition Details page. |
| Favorites and Recent Items | One global header icon. | Can reopen the search page instead of the record. To favorite a Functional Setup Manager task, open it once from Navigator > My Enterprise > Offerings > Opt In Features > Setup icon. |
| Watchlist | Predefined items plus saved searches added with Manage Watchlist; counts refresh periodically; preferences in Navigator > Tools > Set Preferences. | Not available for all product families. |
| Notifications | Bell icon, Things to Finish, email. Tasks: Navigator > Tools > Worklist, or Navigator > Tools > Approvals when enabled (5.7). BPM Worklist: Notifications > Show All > Worklist. | Vacation and delegation rules: BPM Worklist > your name > Preferences > My Rules. |
| Settings and Actions menu | Edit Pages (Page Composer), Edit Page in Visual Builder Studio, Show Help Icons, Record Issue, Sign Out. | If Edit Page in Visual Builder Studio appears, extend that page in VB Studio. |
| Page type | Third URL segment `faces` = ADF (classic); `redwood` = Redwood (VB Studio); second segment `uix` = APEX. | Decides shortcuts, personalization and extension tool. |

#### Redwood or classic: P2P/O2C pages in 26D

Procurement and SCM Redwood pages are switched on by a profile option (Manage Administrator Profile Values or the product profile task; effective at next sign-in) or by an opt-in (Navigator > My Enterprise > New Features, or Offerings > Opt In Features). If an update enables a profile-driven Redwood page by default, resetting the profile restores the classic page. The 26D SCM What's New refers to the My Oracle Support note Classic to Redwood Page Mapping (KB153520) for the full map.

#### AI entry points in the UI

- Home with Ask Oracle (25D, a theme home layout) was removed as a home page layout in 26C; affected environments moved to the News feed layout.
- Where a Redwood page enables it, the Ask Oracle search component tracks recent searches and lets you save filter combinations, for example on My Requisitions (26D).
- Ask Oracle is the conversational pane of the agentic apps: Payables Period Close Workspace, Collector Workspace (read-only inquiries), Billing Operations Workspace, Cash Processing Agent, and the Sales Order Command Center (Order Management > Show More; profile `ORA_FOM_COMMAND_CENTER_AGENTIC_APP_ENABLED`).
- 26D AI Agent Studio adds Ask Oracle plugins that "Oracle Fusion Agentic Home uses to fulfill user requests" (verify availability in your pod). Supplier Portal Advisor opens from Supplier Portal guided journeys. Details: section 10.

### 5.4 Spreadsheet (ADFdi) entry for P2P/O2C

- Install the Oracle ADF Desktop Integration add-in from Navigator > Tools > Download Desktop Integration (Download Desktop Integrator privilege); each release can ship a new version. Microsoft ended Excel 2021 support on October 13, 2026, so use a supported Excel.
- Don't rename sheets, add or delete columns, or hide required or status columns. Double-click `[..]` columns for values; check rows in Status Viewer; nothing changes until you upload. Export to Excel is read-only; the Oracle Visual Builder Add-in for Excel works through REST (section 6).

### 5.7 Approvals and notifications

Approvers act from email, the bell icon, Things to Finish, the Worklist or the Approvals work area. ### 5.10 Productivity tips

- Saved searches: Set as Default and Run Automatically; add them to the Watchlist with Manage Watchlist. Redwood saved searches exist on Purchase Orders, Order Management (25C, shareable with Copy Link), My Requisitions and Self-Service Receiving (26D), but not on the 26D Supplier Portal invoices page.
- Query By Example filters stay applied even when the row is hidden; Clear All removes them.
- Export to Excel takes the selected rows, or all rows if none are selected, within current filters and visible columns.
- Keys: in ADF pages Alt+s saves, Alt+m submits, Alt+c cancels where the letter is underlined; in Redwood tables F2 enters or leaves actionable mode and Esc exits.
- Check the URL (`faces` or `redwood`) before choosing a fix, extension tool or shortcut.
- Bookmark Redwood sales orders; bookmark and share Approvals work area filters.
- Predefined timeouts (not editable): session lifetime 8 hours, idle session 120 minutes, browser inactivity 30 minutes; some pages differ. Sign in once, in one tab of one browser.
- Show Help Icons for page help; Record Issue for the help desk (Redwood pages from 26D); Transaction Console for stuck approvals.
